# Student Records — Spring Boot + MongoDB + JWT

## Folder structure
```
student-records/
├── pom.xml
├── README.md
└── src/
    └── main/
        ├── java/com/example/studentrecords/
        │   ├── StudentRecordsApplication.java
        │   ├── entity/        Student.java, User.java
        │   ├── dto/           StudentRequest.java, RegisterRequest.java, LoginRequest.java
        │   ├── repository/    StudentRepository.java, UserRepository.java
        │   ├── service/       StudentService.java
        │   ├── controller/    StudentController.java, AuthController.java
        │   ├── exception/     GlobalExceptionHandler.java
        │   └── security/      SecurityConfig.java, JwtUtil.java, JwtAuthFilter.java, CustomUserDetailsService.java
        └── resources/
            └── application.properties
```

## One-time setup

1. **Open this folder in VS Code** (`File > Open Folder` → select `student-records`, the one containing `pom.xml`).

2. **Generate the Maven Wrapper** (mvnw/mvnw.cmd) — since global Maven already works on your machine, open a terminal in this folder and run:
   ```bash
   mvn wrapper:wrapper
   ```
   This creates `mvnw`, `mvnw.cmd`, and `.mvn/wrapper/` for you — guaranteed correct, since it's generated by your real Maven install rather than typed by hand.

3. **Make sure MongoDB is running** (Windows Services → "MongoDB" should say Running).

## Run the app

From the project root (the folder with `pom.xml`):

```bash
mvnw.cmd spring-boot:run
```

or, since you have Maven installed globally:

```bash
mvn spring-boot:run
```

Wait for the log to show the embedded server started on port 8080.

## Test it (Postman)

**1. Register**
```
POST http://localhost:8080/auth/register
Body (JSON):
{
  "username": "asha",
  "password": "secret123"
}
```

**2. Login** — copy the `token` from the response
```
POST http://localhost:8080/auth/login
Body (JSON):
{
  "username": "asha",
  "password": "secret123"
}
```

**3. Create a student** — in Postman, set Authorization → Bearer Token → paste the JWT
```
POST http://localhost:8080/students
Body (JSON):
{
  "name": "Asha Rao",
  "age": 20,
  "course": "B.Tech CSE",
  "email": "asha@example.com"
}
```

**4. Read / Update / Delete**
```
GET    http://localhost:8080/students
GET    http://localhost:8080/students/{id}
PUT    http://localhost:8080/students/{id}
DELETE http://localhost:8080/students/{id}
```

**5. Check MongoDB Compass** — connect to `mongodb://localhost:27017` and look for
the `student_records` database with `users` and `students` collections.

## If it won't compile / run
- Confirm `java -version` reports 17.x (your last check showed 21 — if it still does,
  and the build fails with a Java version error, install JDK 17 alongside and point
  `JAVA_HOME` at it; instructions from earlier in this chat).
- Confirm MongoDB service is running before starting the app.
